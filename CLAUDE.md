# Jugglinator

## Language

- Write code comments (`//`, `///`, `/* */`, `#`, docstrings) in English.
- Write commit messages and PR titles/descriptions in English. Keep the task-code prefix, e.g. `LIVELANG: switch language without restart`.
- Russian string literals in code are localization keys (`loc("…")`) and test fixtures: do not translate them. User-facing text goes through `loc(...)` and `Localization/*.lproj`.
